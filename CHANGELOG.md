# История изменений

## 1.0.0

- **Иконка приложения.** Новая иконка-«пульс» для Android (адаптивная) и Windows. Монохромная иконка для уведомлений Android.
- **Шрифт Roboto из макета** на всех платформах. Раньше на Windows использовался Segoe UI.
- **Установщик для Windows** (`beat-setup-x64.exe`):
  - ярлыки в меню «Пуск» и на рабочем столе;
  - правило брандмауэра для синхронизации (только частная сеть);
  - полное удаление, включая автозапуск.
- **Подпись APK постоянным ключом.** Обновления ставятся поверх установленного приложения.
- **Защищённое хранилище.** Ключ группы синхронизации переехал туда из обычных настроек (перенос автоматический).
- **Kanban.** Задачи в последней колонке («Готово») больше не подсвечиваются как просроченные.
- **Ctrl+N** — новая задача или дело на текущем экране.
- **Настройки → «О приложении».** Версия, id устройства, папка с данными (на Windows открывается кнопкой).
- **Исправление.** Контроллер синхронизации менял состояние при уничтожении.

## 0.6.0

- ИИ-помощник на доске проекта. Провайдеры: Anthropic (Claude) и OpenAI-совместимые (LM Studio, Ollama, OpenRouter).
- Разрешения ИИ и очередь изменений на подтверждение.
- MCP-сервер и REST API для внешних агентов, только на 127.0.0.1 и по токену.

## 0.5.0

- P2P-синхронизация по локальной сети: группа с ключом AES-256, подключение по QR-коду или текстовому коду, поиск устройств по UDP.
- На телефоне пункты меню сверх пяти уходят в «Ещё».

## 0.4.0

- Напоминания:
  - на Android — системные уведомления;
  - на Windows — показ из трея.
- Трей и автозапуск на Windows.
- Счётчик напоминаний на сегодня в меню.

## 0.3.0

- «Мой день»: дела на дату и время, шкала дня, режим недели, быстрая форма, ближайшие напоминания.

## 0.2.0

- Kanban: проекты, колонки, карточки, перетаскивание, фильтры, редактор задач.
- Хранилище на журнале событий (основа синхронизации).

## 0.1.0

- Каркас приложения:
  - система модулей;
  - светлая и «болотная» темы;
  - адаптивная оболочка;
  - CI.
