# beat

Планировщик задач для Android и Windows: Kanban для проектов, «Мой день» с задачами на дату и время, напоминания, синхронизация между устройствами без сервера, подключение ИИ.

## Архитектура

```
lib/
  core/            ядро: модули, темы, настройки, адаптивная оболочка, роутер
  modules/         функции приложения, каждая — отдельный модуль
    modules.dart   список подключённых модулей
```

Каждая функция — класс-наследник `AppModule` (`lib/core/module/app_module.dart`). Модуль объявляет свои экраны, а ядро само встраивает их в меню и навигацию.

- **Добавить функцию:** создать папку в `lib/modules/` и добавить модуль в `lib/modules/modules.dart`.
- **Убрать функцию:** удалить строку из `modules.dart`. Пользователь также может выключить модуль в «Настройках».

## Данные

Все изменения записываются в журнал событий (`lib/core/data/`). У каждого устройства свой файл `log/<id-устройства>.jsonl` в папке данных приложения. Состояние собирается слиянием журналов: для каждого поля побеждает изменение с более поздней меткой гибридных часов (HLC). Поэтому синхронизация (v0.5) сводится к обмену файлами журналов.

## ИИ и агенты

Модули отдают ИИ инструменты (`AppModule.agentTools`): Kanban — проекты и задачи, «Мой день» — личные дела. Ими пользуются три клиента, все через один шлюз с разрешениями (`lib/modules/ai/tool_gateway.dart`):

- **Встроенный помощник.** Панель на доске проекта. Работает с Claude (Anthropic API) или с любой моделью через OpenAI-совместимый API (LM Studio, Ollama, OpenRouter).
- **MCP-сервер.** `http://127.0.0.1:47830/mcp` (Streamable HTTP).
- **REST API.** `http://127.0.0.1:47830/api/v1`.

Если включено «Подтверждать изменения», правки от ИИ не применяются сразу: они ждут подтверждения в приложении. Внешний агент получает `change_id` и может проверить статус инструментом `get_change_status`.

Подключение Claude Code (включите «Внешние агенты» в разделе «ИИ и подключения» и скопируйте команду оттуда):

```bash
claude mcp add --transport http beat http://127.0.0.1:47830/mcp --header "Authorization: Bearer <токен>"
```

REST:

```bash
curl -H "Authorization: Bearer <токен>" http://127.0.0.1:47830/api/v1/tools
curl -X POST -H "Authorization: Bearer <токен>" -d '{}' http://127.0.0.1:47830/api/v1/tools/list_projects
```

## Адаптивность

| Ширина | Навигация |
|---|---|
| < 600 px (телефон) | нижняя панель |
| 600–1100 px (планшет) | rail |
| ≥ 1100 px (десктоп) | боковое меню, как в макете |

## Темы

Светлая (токены Material 3 из макета), тёмная «болотная» и режим «как в системе».

## Сборка

```bash
flutter pub get
flutter run -d windows
flutter build apk --release
flutter build windows --release
```

Релизы собирает GitHub Actions по тегу `vX.Y.Z` (`.github/workflows/release.yml`). Готовые APK и zip для Windows публикуются в GitHub Releases.
